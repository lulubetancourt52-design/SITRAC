

\# SITRAC

Sistema Inteligente de Transporte y Gestión de Rutas



\## Descripción

SITRAC es un sistema desarrollado en C++ para gestionar ciudades, rutas, pasajeros, solicitudes de viaje, historial y reportes.



\## Módulos

1\. Ciudades

2\. Rutas

3\. Pasajeros

4\. Cola de solicitudes

5\. Historial

6\. Búsquedas

7\. Reportes

8\. Archivos



\## Requisitos

\- Compilador C++ compatible con C++17.

\- Git.



\## Compilación

Desde la carpeta principal del proyecto:



g++ -std=c++17 src/main.cpp -o SITRAC



\## Ejecución

En Git Bash:



./SITRAC



\## Estructuras de datos

\- Listas enlazadas.

\- Grafo mediante listas de adyacencia.

\- Cola enlazada.



\## Uso de inteligencia artificial

Se utilizó inteligencia artificial como apoyo para comprender estructuras de datos, revisar errores y orientar el desarrollo. El código fue revisado y probado por el estudiante.
